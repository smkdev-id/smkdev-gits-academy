# Fintech

Fintech adalah aplikasi Flutter sederhana yang dirancang untuk mengelola dan memantau keuangan pribadi. Aplikasi ini dibangun menggunakan [FlutterFlow](https://flutterflow.io), platform yang memungkinkan pengembangan aplikasi Flutter dengan antarmuka visual.

## Getting Started

FlutterFlow projects are built to run on the Flutter _stable_ release.

### Prerequisites

- Ensure you have Flutter installed. You can get it from [Flutter's official site](https://flutter.dev/docs/get-started/install).
- Ensure you have Dart installed. Dart is included with Flutter.

## Installation

1. Clone the repository:

    ```bash
    git clone <repository-url>
    ```

2. Navigate to the project directory:

    ```bash
    cd fintech
    ```

3. Add necessary dependencies:

    ```bash
    dart pub add dev:build_runner
    ```

4. Run build_runner to generate code:

    ```bash
    flutter packages pub run build_runner build --delete-conflicting-outputs
    ```

## Running the Project

1. Ensure you are in the project directory.
2. Run the Flutter application:

    ```bash
    flutter run
    ```

## Additional Information

For more details on FlutterFlow and how to integrate with Flutter, refer to [FlutterFlow Documentation](https://docs.flutterflow.io).
